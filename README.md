# 数字人示例代码

本目录包含两个数字人应用场景的完整示例代码，帮助开发者快速理解不同业务场景下的架构设计与实现方式。

## 示例目录

### 1. 数字人交互聊天示例 (`digital-human-interactive-chat`)

**应用场景**：智能客服、虚拟主播互动、教育陪练等需要实时对话的场景

**核心功能**：客户端与数字人进行实时双向交互对话

**架构特点**：
- **双向交互**：用户说话 → ASR 语音识别 → LLM 生成回复 → TTS 语音合成 → 数字人实时回应
- **双角色架构**：客户端 + 业务后台
- **实时通信**：通过 WebSocket 驱动数字人，RTC 拉流播放音视频


---

### 2. 数字人实时播报场景示例 (`digital-human-real-time-broadcasting-scenario`)

**应用场景**：商场导览、机场车站播报、电梯广告屏、数字人直播等单向播报场景

**核心功能**：编排端配置播报内容，播放端拉流播放数字人音视频

**架构特点**：
- **单向播报**：编排端配置内容 → 业务后台定时驱动 → 播放端拉流播放
- **三方架构**：编排端（配置） + 业务后台（驱动） + 播放端（播放）
- **集中管理**：支持多个播放端同时接收同一播报内容

---

## 架构对比

| 特性 | 交互聊天示例 | 实时播报示例 |
|------|------------|------------|
| **交互模式** | 双向实时交互 | 单向播报 |
| **角色架构** | 双角色（客户端 + 业务后台） | 三角色（编排端 + 业务后台 + 播放端） |
| **驱动方式** | 用户说话触发 ASR→LLM→TTS | 编排端配置内容后定时驱动 |
| **适用场景** | 智能客服、虚拟主播互动、教育陪练 | 商场导览、机场播报、广告屏、直播 |
| **通信复杂度** | 较高（需处理实时音频采集） | 较低（仅需文本/音频驱动） |

## 快速开始

每个示例目录都包含完整的业务后台和各端客户端代码：

- **业务后台**：Node.js + Express，提供 API 接口和数字人驱动逻辑
- **Web 客户端**：React / Vue 示例，使用 ZEGO Express SDK 拉流播放
- **移动端客户端**：Android / iOS 示例，使用 ZEGO Express SDK 拉流播放

详细接入指南请查看各示例目录下的 README.md 文件。
